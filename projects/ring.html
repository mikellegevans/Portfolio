Motion Ring — Wearable Mouse

Personal Project · Self-Directed
Oct 2026 – Present

A ring-sized wearable that turns hand motion into cursor control. An onboard IMU tracks orientation and streams pointer movement and clicks to any device over Bluetooth, no software to install on the other end.

What I built

A wearable mouse the size of a ring. A BNO055 IMU reads orientation over I2C, and firmware on the microcontroller converts that motion into real-time pointer movement, sending it to a host device as a standard Bluetooth mouse. I designed the circuit, wired and assembled the hardware, and wrote the embedded C++ from scratch.

Making it wearable

The first version ran on a full-size ESP32 dev board, which proved the concept but was far too big to wear. I moved the whole build onto a tiny ESP32-S3, which uses native USB and a different pin layout, then re-mapped the wiring and got the motion tracking working again on the smaller board.

Where it is now

Motion-to-cursor and clicks work over Bluetooth. Motion-to-cursor and clicks work over Bluetooth. I’m currently adding scroll control and designing a 3D-printed housing so the ring is comfortable to wear and holds up to everyday use.
