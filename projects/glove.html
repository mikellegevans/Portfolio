ASL Recognition Glove

Personal Project · Self-Directed
2026 – Present

A glove that reads hand shapes using five flex sensors, one per finger, as a first step toward recognizing American Sign Language letters.

Add Photoglove-1.jpg
Add Photoglove-2.jpg

What I built

A glove with a flex sensor sewn along each finger. Each sensor sits in a voltage-divider circuit feeding an ESP32, so the amount a finger bends changes the voltage the board reads. The board is wrist-mounted, and all five sensors read live while the glove is worn.

Calibration

Raw sensor values differ from finger to finger and person to person, so I wrote an auto-calibration routine: while the hand opens and closes, the firmware learns each finger's minimum and maximum and maps the readings to a clean 0–100% bend. That makes it possible to tell finger positions apart reliably instead of guessing from raw numbers.

What's next

The hardware and sensing are done. The next phase is recognition, mapping sensor patterns to letters, starting rule-based and then training a machine-learning model to improve accuracy.
